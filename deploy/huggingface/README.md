# QuizBank demo

A question bank for instructors: import Canvas quizzes, give them online with automatic grading, and use machine learning to find broken questions, suggest scores for written answers, and group questions by topic.

This is a public demo. Sign in with the account shown on the sign-in page. Anything you change is shared with other visitors, and everything resets when the Space restarts.

Code, documentation, and how each ML feature was evaluated: [github.com/reecemill/quizbank](https://github.com/reecemill/quizbank)
